FILES
- transformations-widget.html: paste the whole file into an Elementor Custom HTML widget
- transformation-01.jpg to transformation-10.jpg: resized web images

SETUP
1. WP Admin > Media > Add New, upload all 10 jpg files.
2. Copy each image URL into the `images` array in the script (marked EDIT THIS).
3. Membership links and the login link are already set in the `plans` array and
   `loginUrl`. Edit prices or labels there if they change. Leave a price as ""
   to hide it on the card.
4. Paste the full file into a Custom HTML widget.
